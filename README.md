# Snowflake Data Engineering

A hands-on learning repository documenting my practical experience with Snowflake, SQL, data loading, and cloud data warehousing.

## About This Repository

This repository contains structured exercises and practical implementations based on Snowflake's official documentation and tutorials.

The objective is to build a solid foundation in data engineering through hands-on practice, reproducible SQL scripts, and clear technical documentation.

## Completed Tutorials

### 01 — Snowflake Basics

Completed the official **Snowflake in 20 Minutes** tutorial.

**Topics covered:**
- Snowflake database, schema, table, and virtual warehouse setup
- Snowflake CLI configuration on Windows
- CSV file staging using `PUT`
- Data loading using `COPY INTO`
- SQL queries and basic data manipulation
- Data validation and troubleshooting

**Results:**
- 5 CSV files uploaded successfully
- 25 records loaded
- 0 loading errors
